# File Management System

This repository contains two implementations of a simple file management system written in .NET 6.

- **Console Application** (`FileManagementSystem`)
- **Windows Forms UI** (`FileManagementSystemUI`)

## Building

1. Install the .NET 6 SDK.
2. Navigate to the desired project directory (`FileManagementSystem` or `FileManagementSystemUI`).
3. Run `dotnet build`.

## Running

To run the console version:

```bash
dotnet run --project FileManagementSystem
```

To run the Windows Forms UI:

```bash
dotnet run --project FileManagementSystemUI
```

The UI version provides text boxes and buttons to list, copy, move and delete files.
