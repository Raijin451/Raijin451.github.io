# File Management System

This repository contains a simple console-based file management system written in .NET 6.

## Building

1. Install the .NET 6 SDK.
2. Navigate to the `FileManagementSystem` directory.
3. Run `dotnet build`.

## Running

```bash
dotnet run --project FileManagementSystem
```

The application will display a menu that allows listing, copying, moving and deleting files.
